# 🎓 Нейрон — Интерактивный опрос студентов ДГТУ

Современное веб-приложение для сбора болей, предложений и обратной связи от студентов ДГТУ по цифровым сервисам (расписание, личный кабинет, деканат, общаги, студ. жизнь).

Разработано по инициативе студенческого сообщества «Нейрон».

---

## 🚀 Быстрый запуск на локалке

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск приложения (Фронтенд + Сервер + БД одной командой)
```bash
npm run dev
```

После запуска:
* **Клиентский опрос (студенческий интерфейс):** [http://localhost:5173](http://localhost:5173)
* **Серверный API & хранилище:** [http://localhost:3001](http://localhost:3001)

---

## 🎯 Возможности и функции

### 1. Пошаговый интерактивный визард (4 шага)
* **Шаг 1: Направления сервисов** (6 интерактивных категорий: *Учёба и расписание*, *Документы и справки*, *Кампус и общежития*, *Студенческая жизнь*, *Цифровые сервисы и IT*, *Своя идея*).
* **Шаг 2: Выбор конкретных болей** (динамические чипсы/теги под выбранную категорию + возможность вписать свою проблему).
* **Шаг 3: Свободная мысль и приоритет** (текстовое поле до 1000 символов с живым счетчиком и динамическими плейсхолдерами-примерами + оценка критичности: *«Терпимо 👌»*, *«Очень бесит 😤»*, *«Критично 🔥»*).
* **Шаг 4: Приватность и отправка** (выбор: 100% анонимно по умолчанию либо указание ФИО и Telegram `@username` для приглашения в закрытое бета-тестирование).

### 2. Защита от накрутки и спама
* Фиксация прохождения в `localStorage` и `Cookie` (`unio_voted=1`).
* Экран повторного захода с защитой от повторного спама.
* Предусмотрена кнопка **«Пройти ещё раз (для тестов)»** для удобной отладки команды.
* In-memory rate limiting на стороне Express сервера по IP.

### 3. Скрытая панель аналитики и роли доступа (/admin)
* Доступна **только по прямому переходу по URL**: [http://localhost:5173/admin](http://localhost:5173/admin) или `/#admin` (в публичном интерфейсе студента упоминания и кнопки полностью скрыты).
* **Система ролей:**
  1. 👑 **Главный администратор (Super-Admin):**
     - Вход по мастер-ключу из файла `.env` (`ADMIN_PASSWORD`);
     - Просмотр статистики, фильтрация, поиск, экспорт CSV / JSON;
     - Удаление отдельных отзывов и полная очистка базы;
     - **Создание и отзыв гостевых ключей** во вкладке *«👥 Гостевые доступы»*.
  2. 👁 **Наблюдатель (Viewer / Только чтение):**
     - Вход по гостевому ключу, выданному администратором;
     - Полный доступ к просмотру графиков, статистики, ленты ответов и экспорту;
     - Кнопки удаления и очистки скрыты в интерфейсе и строго заблокированы на уровне бэкенда (403 Forbidden).
* **Безопасность:**
  - Защита от брутфорса (блокировка IP на 15 минут при 5 неверных попытках);
  - Искусственная задержка (500 мс) против высокоскоростных автосканеров;
  - Сравнение ключей через constant-time `crypto.timingSafeEqual`.

## 📁 Структура проекта

```
site-call/
├── data/
│   └── votes.json          # Локальная база данных ответов (атомарная запись)
├── server/
│   ├── index.js            # Express сервер, роуты API, rate-limiting, куки
│   └── db.js               # Слой данных, подсчет агрегированной статистики
├── src/
│   ├── components/
│   │   ├── Header.jsx          # Шапка с логотипом Нейрон, бейджем ДГТУ и анонимности
│   │   ├── ProgressBar.jsx     # Индикатор прогресса шагов
│   │   ├── CategoryIcon.jsx    # Четкие векторные SVG-иконки
│   │   ├── Step1Category.jsx   # Шаг 1: выбор категории
│   │   ├── Step2Subcategory.jsx# Шаг 2: выбор подкатегорий и тегов
│   │   ├── Step3Details.jsx    # Шаг 3: текст идеи и важность
│   │   ├── Step4Privacy.jsx    # Шаг 4: приватность и контакты
│   │   ├── SuccessScreen.jsx   # Экран благодарности и статистики
│   │   ├── AlreadyVotedScreen.jsx# Экран для уже проголосовавших
│   │   └── AdminModal.jsx      # Модальная панель администратора с аналитикой
│   ├── data/
│   │   └── surveyData.js       # Категории, вопросы и уровни важности
│   ├── App.jsx             # Корневой компонент и машина состояний
│   ├── index.css           # Дизайн-система (адаптивная, стекло, тени, анимации)
│   └── main.jsx            # Точка входа React
├── index.html              # HTML разметка с шрифтами и мета-тегами
├── vite.config.js          # Конфиг сборщика с прокси на бэкенд
└── package.json            # Скрипты и зависимости
```
